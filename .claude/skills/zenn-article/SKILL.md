# Zenn 記事を書く手順

## 1. 着手前に決める（私に確認する）
- テーマと、この記事で読者が得られるもの（1文）
- 想定読者（どの程度の知識を前提にするか）
- 根拠にする情報源（公式ドキュメント、自分で動かした結果など）

## 2. 作成
- slug は英小文字・数字・ハイフンで、12〜50文字（Zenn の仕様）。内容が分かる名前にする
- `articles/<slug>.md` を作る。frontmatter は次の形式で、必ず `published: false` で始める:
  ```
  ---
  title: "..."
  emoji: "🤖"
  type: "tech"
  topics: ["a", "b"]   # 小文字。最大5個（Zenn の仕様）
  published: false
  ---
  ```
- 画像は `images/<slug>/` に置き、本文からは `/images/<slug>/xxx.png` で参照する

## 3. 構成（既存記事に合わせる）
1. `## はじめに` 動機・この記事で分かること
2. 概念の説明 身近なたとえ話を使う
3. 具体例・実装 動作確認したコードだけを載せる。未確認なら「イメージ」と明記する
4. まとめ

## 4. 書き方のルール
- 「です／ます」調。見出しは `##` から（`#` は使わない）
- 事実を捏造しない。バージョン・日付・仕様は、確認できた出典のものだけ書く
- 確認できなかった点は、本文に書かず、私に報告する
- 長い調査メモは `notes/` に置く（記事には載せない）

## 5. 仕上げ
- `zenn-review` スキルでチェックしてから、私にレビューを依頼する
- `published: true` への変更と `git push` は、私が指示したときだけ行う
