# Zenn 記事の公開前チェック

対象の記事（`articles/<slug>.md`）を読み、次を確認して、結果を「OK / 要修正（行番号つき）」の形で報告する。
記事の書き換えは、私が指示するまで行わない。

## 形式
- [ ] frontmatter に title / emoji / type / topics / published がある
- [ ] topics は小文字で、5個以内
- [ ] slug（ファイル名）が英小文字・数字・ハイフンで、12〜50文字
- [ ] 見出しが `##` から始まっている（`#` を使っていない）
- [ ] 画像の参照先（`/images/<slug>/...`）が、`images/<slug>/` に実在する

## 内容
- [ ] 「はじめに」で、動機と読んで分かることが書かれている
- [ ] 専門用語が、初出で説明されている
- [ ] コードは動作確認済みか、未確認なら「イメージ」と明記されている
- [ ] バージョン・日付・数値に、根拠（出典）がある。根拠が確認できないものは列挙する
- [ ] 前後で矛盾する記述がない。見出しと本文の内容が合っている

## 公開前の安全確認
- [ ] APIキー、トークン、内部のホスト名、IP アドレス、アカウント ID が含まれていない
- [ ] 他人の文章・画像を、出典なしで転載していない
- [ ] `published` の値が、意図した状態（下書きなら false）になっている

## 報告の形式
1. 重大な問題（公開前に必ず直す）
2. 改善案（任意）
3. 確認できなかった点
